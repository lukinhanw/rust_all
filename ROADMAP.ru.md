### Установщик
- Исправления после ревью (v0.3.0): rs-du хранит список карантина рядом со своим exe (писать туда может только администратор), `payload\` двумя уровнями выше берётся только из `target\release`, rtaskmgr и rust-explorer сохраняют и возвращают чужие настройки диспетчера задач и папок, rust-search сначала возвращает поиск Windows и только потом удаляет свои файлы, DiagTrack оставлен debloat, один разбор вывода `reg query` с тестом. *тесты, собрано*
- Параметры без Проводника (Win+I и меню панели): Параметры — Store-приложение, оно открывается только при Проводнике в роли оболочки, поэтому скрытый помощник запускает Проводник, ждёт его панель, открывает страницу, выводит окно на передний план (в том числе поверх полноэкранной игры) и возвращает rust-explorer после закрытия Параметров; зависший процесс Параметров сначала убивается. Панель скрывается только для полноэкранных игр и видео. *собрано, проверено вручную*
- Один `plugin-launcher.exe`, в который вшиты все плагины (распаковка в Program Files, не в %TEMP%), статический CRT, тёмное окно на Win32/GDI. *запускалось*
- «Install WinRust» ставит недостающее по порядку (topbar раньше rust-explorer), когда всё стоит, обновляет; «Удалить всё» удаляет в обратном порядке. *собрано*
- Сбой установки откатывает свои изменения (кроме обновления рабочей копии); исходные значения (WSearch, строка поиска, настройки Проводника, службы) сохраняются в `HKLM\SOFTWARE\plugin-launcher\<плагин>` и возвращаются при удалении; несмертельные ошибки пишутся в `%ProgramData%\plugin-launcher\install.log`. *собрано*
- Точка восстановления перед установкой. *собрано*
- Выбор, что ставить (#7): в окне галочка у каждого компонента, в командной строке несколько имён или `all`; упавший или пропущенный компонент не останавливает остальные, ошибки перечисляются в конце. Отсутствие службы Windows Search (урезанные сборки LTSC) для rust-search при установке и удалении теперь предупреждение, а не ошибка. *собрано*
- Пользователь сеанса, а не элевированная учётная запись (#4): если в UAC введён другой администратор, пользовательские настройки (HKCU, задачи планировщика, профиль PowerShell, право на канал rust-search, Run-ключ rs-launcher, HKCU-политики debloat) пишутся владельцу explorer.exe (или topbar / rust-explorer / rs-shell) этого сеанса через `HKU\<SID>`. Если пользователя определить нельзя, установка останавливается до любых записей. Удаление продолжается с предупреждением. *тесты (подмена ключей), собрано*
- Одна кнопка ставит недостающее **и** обновляет установленное: запуск нового `WinRust.exe` доносит исправления до всех плагинов (v0.2.1). *собрано*
- Командная строка: `list | install <плагин>...|all --yes | update <плагин> | uninstall <плагин> | rollback --yes`, коды выхода 0/1/2; окно и командная строка вызывают одни и те же функции. Запускались только команды, которые ничего не меняют. *запускалось (частично)*
- `update` и `scripts\update-plugin.ps1`: переустановка из `payload\` на диске без пересборки установщика. *запускалось*
- Английский по умолчанию, переключатель языка (English, Русский, 日本語, Português) в установщике и в меню панели; выбор хранится в `%ProgramData%\WinRust\lang.txt`. *тесты*
- Устройство кода: один cargo workspace; установщик разделён на `install/` (файл на плагин), `cli.rs`, `ui.rs`; общий crate `winrust-common` (переключатель языка, чтение MFT); один список `payload.txt` для сборки и скриптов; CI на GitHub Actions. *тесты*

### Плагины
- **rust-search**: служба поиска по NTFS + Alt+Space; отключает WSearch, блокирует SearchHost.exe, прячет строку поиска. Правый клик по результату: переименовать, в корзину, «удалить навсегда + почистить реестр» (сканирование → подтверждение → удаление; реестр сначала сохраняется в `%LOCALAPPDATA%\rs-search\registry-backups\*.reg`). *тесты, запускалось*
- **rtaskmgr-win32**: заменяет диспетчер задач через IFEO-Debugger (`taskmgr.exe` не трогается); при панике пишет `%APPDATA%\rtaskmgr\crash.log` и открывает настоящий Taskmgr. *тесты, запускалось*
- **topbar**: нижняя панель в стиле Windows 11 вместо панели задач; `topbar.exe --restore` возвращает панель задач. Вместе с ним ставятся хоткеи reshell, rs-du, блок профиля PowerShell (`src/install/profile.ps1`, Windows PowerShell 5.1 и pwsh 7). *запускалось; блок профиля только на временном профиле*
- **Страховка reshell**: если topbar не запущен, а панель задач скрыта, два раза подряд (~10 с), запускает `topbar.exe --restore`. *тесты; сценарий «убить topbar» не проверялся*
- **Хоткеи reshell**: Win+D (показать рабочий стол) и Win+I (Параметры) работают без Проводника, как Win+E (v0.2.1). *запускалось*
- **Стили** (v0.3.0): шестерёнка в левом краю панели переключает Обычный / Терминал / Плавающий док / Тайлинг; панель, rust-explorer и окно поиска перекрашиваются сразу (широковещательное сообщение, `%ProgramData%\WinRust\style.txt`). Док не занимает места на экране и уезжает из-под развёрнутых окон; Тайлинг ставит панель наверх и умеет раскладывать окна плиткой. *запускалось*
- **Вид topbar** (v0.3.0): значок сети рисуется сам (дуги Wi‑Fi по сигналу, крестик без сети, «!» без интернета, по данным Windows о подключении); новая панель Wi‑Fi (статус, карточка подключённой сети с отдельной кнопкой «Отключиться», сохранённые и открытые сети, строки появляются по очереди); меню только из текста с подсказками клавиш; выбор языка ввода (левый клик по ENG/RUS); трей проявляется с анимацией, стрелка поворачивается. *запускалось*
- **rust-explorer**: файловый менеджер (вкладки, иконки, копирование/вставка/удаление через IFileOperation, контекстное меню, перетаскивание), рисует рабочий стол, отключает Проводник как оболочку через `rs-shell --overlay` (не позже 90 с после входа: Windows 26300 больше не пишет отметки автозагрузки, которых он ждал, v0.2.1), урезает службы. *тесты, запускалось*
- **rs-du**: чистильщик диска (анализ MFT, кеши, `target`/`node_modules`, корзина, карантин на 30 дней), запускается из меню панели. *тесты*
- **wiztree**: карта занятого места по MFT. *тесты (только раскладка); на живом диске не запускался*
- **photoview**: просмотр фото на WIC, поворот по EXIF, пункт «Открыть с помощью». *запускалось; EXIF-ориентации 5 и 7 не проверялись*
- **debloat**: службы и политики (телеметрия, Copilot, Recall, реклама, фоновый Edge), старые значения в `%ProgramData%\winrust-debloat\undo.txt`, `--undo`. *сухой прогон запускался; `--apply`/`--undo` нет*
- **purge**: удаляет предустановленные Store-приложения (установленные и из образа) и задачи телеметрии, как Tiny11; OneDrive и Edge только с `--onedrive` / `--edge`. НЕОБРАТИМО, журнал в `%ProgramData%\winrust-purge
emoved.txt`. `purge.exe` показывает список, `--ask` просит ввести YES (меню по правому клику на панели), `--apply` удаляет. Защищённые имена (Магазин, Параметры, Пуск, среды выполнения) проверены тестами. *тесты, пробный запуск выполнен; `--apply` не запускался*
- **Стиль «Белая дорога» и новые панели topbar**: пятый, светлый стиль (слоновая кость, золотой акцент, треугольники, часть с золотой обводкой, через GDI+ за панелью, её окошками, rust-settings; список Проводника белый); быстрые настройки и Wi-Fi перерисованы: плитки с круглыми значками и подписями внутри, ползунки на одной карточке с ручкой с тенью, батарея в «пилюле» и круглая шестерёнка, переключатель как в iOS, подключённая сеть на своей карточке с галочкой (скорость и защита при наведении, там же появляется «Отключиться»), остальные сети на одной карточке с тонкими разделителями; правый клик по сети открывает меню (подключиться / отключиться, забыть, известные сети); при подключении дуги сигнала бегут, а под строкой скользит полоска, пока сеть не подключится или не пройдёт 25 с. rust-settings: значения, которые раньше перебирались по клику (разрешение, частота, масштаб, ориентация, дисплей, режим экранов, схема питания, отключение экрана и сон), открывают анимированный выпадающий список с галочкой у текущего (работают стрелки, Enter, Esc и колесо); дисплей без имени в EDID называется «Встроенный экран», а не `\\.\DISPLAY1`. `topbar --preview quick|wifi` показывает панель отдельно. *собрано, тесты; панели сняты в «Белой дороге» и «Тайлинге», rust-settings и Проводник в «Белой дороге»*
- **Новый вид** (все программы): общая палитра теперь нейтральный графит с системным синим Apple (Обычный), полуночный с индиго (Плавающий док), обновлённые Терминал и Тайлинг; везде зелёный/жёлтый/красный Apple для состояний; Segoe UI Variable и Segoe Fluent Icons на Windows 11 (Segoe UI / MDL2 на Windows 10). rtaskmgr, установщик, wiztree и photoview перешли со своих цветов на тот же графит. rust-settings перерисован в духе Системных настроек macOS: цветные значки разделов, сгруппированные скруглённые карточки с тонкими разделителями и заголовками групп, переключатели как в iOS, сглаженные фигуры (GDI+), колонка по центру, плавающая нижняя панель. `WINRUST_STYLE=<имя>` показывает стиль в одном процессе. *собрано, тесты; скриншоты rust-settings проверены во всех четырёх стилях, остальные программы после изменения не смотрели*
- **rust-settings** (первые шаги): небольшое окно Параметров, которому не нужны ни Проводник, ни Store-приложение Параметры. Страницы: Экран (разрешение и частота основного дисплея: изменение временное, Enter оставляет, Esc или 15 с возвращают; сначала проверка `CDS_TEST`), Звук (ползунок громкости и выключение звука на устройстве по умолчанию, Core Audio), Питание и диски (батарея, смена схемы питания, свободное место на постоянных дисках), Сеть (адаптеры Wi-Fi/Ethernet и скорость связи; Wi-Fi: включение/выключение, подключение к сохранённым, открытым и новым сетям с паролем, введённым в окне (профиль через WLAN API, неудачная попытка его удаляет), скрытые сети, отключить/забыть по правой кнопке, итог с текстом причины от Windows; сканирование примерно раз в 30 с, а не при каждом обновлении), Персонализация (тёмная тема приложений и системы, прозрачность, акцент на заголовках: четыре значения в HKCU), О системе (только чтение), Другие разделы (открывает системные страницы через существующий помощник). Только документированные вызовы Win32, ничего не запускается как команда. Ставится как wiztree (файл в Program Files и ярлык в меню Пуск); после установки Win+I и меню панели открывают его для точных адресов `ms-settings:` (экран), `sound`, `personalization`/`colors`/`themes`, `powersleep`/`storagesense`, `network-status`, `about`, остальные идут в Параметры Windows. Подключение к установщику только собрано, не запускалось; Ethernet: только настоящие карты (Hyper-V, VPN и Wi-Fi Direct скрыты), у каждой адрес, скорость и точка «интернет» от Network List Manager; по клику IPv4/IPv6, шлюз, DNS, DHCP или вручную, MAC. Дальше: Bluetooth, громкость по приложениям. Ввод пароля Wi-Fi на живой сети ещё не пробовали. Написано с нуля (код из PR #14 не использовался). ## Известные ограничения
- Системные компоненты отключаются или обходятся (обратимо), а не удаляются: удаление `taskmgr.exe` или поиска Windows сломало бы защиту системы.
- Нужны права администратора.
- Win+S и «Пуск» по-прежнему открывают поиск Windows.
- Когда оболочка rust-explorer, приложения Магазина, которые держит Проводник (страницы Параметров Windows, которых нет в rust-settings, окно входа Microsoft в Outlook/Teams, #98, #109), требуют запущенный Проводник; войдите один раз, пока Проводник — оболочка.
