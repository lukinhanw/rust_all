# WinRust

**Rust で書かれた Windows シェル: 標準のものより高速で軽量です。** Windows の一部を置き換える小さなネイティブ プログラム群 (.NET も Electron も不要): タスクバー、エクスプローラー、ファイル検索、タスク マネージャー、さらにディスク クリーナー、ディスク マップ、フォト ビューアー。インストーラー 1 つで導入でき、ボタン 1 つですべて元に戻せます。

[English](README.md) | [Русский](README.ru.md) | 日本語 | [Português (Brasil)](README.pt-BR.md) | [简体中文](README.zh.md)

> **最初にお読みください。** WinRust は Windows 検索を無効にし、タスクバーを隠し、シェルとしてのエクスプローラーを無効にすることもできます。exe にはコード署名がないため、SmartScreen が警告を表示します。インストール前に復元ポイントが作成されますが、まず予備のマシンか VM で試してください。

## インストール

1. [最新リリース](https://github.com/Lemxy/WinRust/releases/latest)から `WinRust.exe` をダウンロードします (Windows 10/11、x64)。
2. 管理者として実行します。
3. 必要なコンポーネントにチェックを入れ、インストール ボタンを押します。新規インストールでは `rust-explorer` のチェックは外れています。チェックすると Windows のエクスプローラー シェルを置き換えます (または topbar の行にある歯車の **Shell: rust-explorer** スイッチを使います)。正しい順序でインストールされ、失敗またはスキップされたものがあっても他は止まらず、ウィンドウに問題点が一覧表示されます。

Windows 検索は任意です。Windows 検索サービスのない軽量化された Windows (たとえば不要なものを削った LTSC イメージ) では、その手順は失敗にならず警告付きでスキップされます。

UAC が**別の管理者**のパスワードを求めた場合でも、ユーザーごとの設定 (スタートアップ項目、スケジュールされたタスク、PowerShell プロファイル、検索の権限) は、入力した管理者ではなく、サインイン中のユーザーに適用されます。インストーラーがそれを特定できない場合は、何も変更せずに停止します。

**自動更新:** 初回インストール後、`WinRust-update` というスケジュールされたタスク (SYSTEM で実行、UAC の確認なし) が、起動時と 1 日 1 回、最新リリースを確認します。新しい `WinRust.exe` (リリースが個別に添付するプログラムがあればそれも) をダウンロードし、各ファイルをプロジェクトの鍵で署名されたマニフェストと照合します (改ざんされた、または署名のないリリースは拒否)。その後、新しい `WinRust.exe` が、内蔵しているものと異なるインストール済みプログラムを置き換えます。置き換えるのはすでにインストールされているファイルだけです。実行中のプログラムは、次回の起動時 (サインインまたは再起動) に新しいバージョンに切り替わります。ログ: `%ProgramData%\plugin-launcher\install.log` (`autoupdate:` の行)。無効にするには、タスク スケジューラで `WinRust-update` タスクを無効にします。**すべて削除**でもこのタスクは削除されます。

**手動更新:** リリース ページから新しい `WinRust.exe` をダウンロードし、管理者として実行して、更新またはインストールするコンポーネントを選びます。既存の `rust-explorer` は、更新時には既定で選択されたままになります。設定と、保存された Windows の元の値は保持されます。

インストーラーは英語で表示されます。右上の言語ドロップダウン (English、Русский、日本語、Português (Brasil)、简体中文)、バーの歯車 (**バーの設定 → 言語**)、rust-settings の **個人用設定** ページ (**表示言語**) のどれからでも切り替えられます。選択は `%ProgramData%\WinRust\lang.txt` (`en`、`ru`、`ja`、`pt`、`zh`) に保存され、切り替えたプログラムはすぐ描き直され、ほかのプログラムは起動時に読み込みます。変更後は再起動 (またはサインアウト) してください。

## 削除

- インストーラー ウィンドウの **すべて削除** で、すべてが元に戻ります: Windows 検索、タスクバー、エクスプローラー、サービスが復活します。
- インストーラーがない場合 (ウイルス対策ソフトが削除した場合など): **設定 → アプリ → インストールされているアプリ → WinRust → アンインストール** で「WinRust を削除」と同じことができます。
- プラグインを 1 つずつ削除するには: `plugin-launcher uninstall <plugin>` ([コマンド ライン](#コマンド-ライン)を参照)。
- **画面にタスクバーもデスクトップもなくなった場合:** Ctrl+Alt+Del → タスク マネージャー → 新しいタスクの実行 → `explorer.exe` と操作し、その後インストーラーを実行して「すべて削除」を押します。

アンインストール時、`rust-explorer` はインストール前に保存したサービスの開始値と svchost のグループ化しきい値を復元します。これらのバックアップがない古いインストールでは現在の値が維持され、警告が報告されます。

## インストールされるもの

| プラグイン | 得られるもの | Windows で変更されるもの |
|---|---|---|
| **rust-search** | すべての NTFS ドライブを対象にしたファイル検索 (Alt+Space)。topbar があれば Win+R で実行モードが開きます: 履歴、フォルダー補完 (Tab)、Ctrl+Shift+Enter で管理者として実行 | Windows 検索サービスを無効にし、SearchHost.exe をブロックし、タスクバーの検索ボックスを隠します |
| **rtaskmgr-win32** | タスク マネージャー (Ctrl+Shift+Esc で開きます) | `taskmgr.exe` がこちらにリダイレクトされます (システム ファイルには手を加えません)。ディスク クリーナー **rs-du** も一緒にインストールされます。**速度**ページには、オプトインで元に戻せるスイッチがあります: ゲーム / 作業プロファイル (バックグラウンド サービスを停止し、ランチャーや同期アプリを終了し、再び起動)、メモリのスタンバイ キャッシュの消去 (今すぐ、または topbar の実行中に自動で)、Windows のスタート メニュー、ウィジェット、スマートフォン連携のプロセスのブロック、サードパーティの更新ツールの代わりに週 1 回の `winget upgrade`、ビルド キャッシュとゲーム ライブラリの Defender 除外、高速 NTFS (最終アクセス日時と 8.3 名なし)、広告をブロックする hosts ファイル。**スタートアップ**には、ログオン/起動タスクとサードパーティの自動開始サービスも一覧表示され、それぞれが直近の起動をどれだけ遅くしたか (Windows 自身の起動ログ) が分かります。**遅い原因**には、ドライバーの時間 (DPC/割り込み)、ハングしたウィンドウ、遅いディスク、起動時間が表示されます。アンインストールするとすべて元に戻ります |
| **topbar** | Windows 11 風の下部バー: ウィンドウ、時計、音量、メニュー | 標準のタスクバーを隠します。**reshell** (ホットキー: Win+Ctrl+1/2/3 と Win+\` でデスクトップを切り替え (Win+1..9 はバーのアプリ ボタンを開く)、Win+D でデスクトップを表示、Win+I で設定、Win+E でファイル マネージャーを開く。バーが落ちた場合はタスクバーを復活させます)、**rs-du**、PowerShell プロファイル内のブロック (`zoxide`、`grep`=rg、`ll`=eza、`cat`=bat。存在しなければ何もしません) も一緒にインストールされます。歯車メニューには短いページがあります: テーマ、色と透明度 (バーと WinRust ウィンドウの任意の色、バーの不透明度)、テンプレート (自分の外観を保存して切り替え)、バー (下/左/右の端、サイズ、自動的に隠す、Windows 10 のように左端にボタンを配置)、すべて初期設定に戻す |
| **rust-explorer** | タブ付きのファイル マネージャーとデスクトップ | フォルダーとドライブはこちらで開き、**エクスプローラーはシェルではなくなります** (topbar が失敗した場合は自動的に戻ります)。新規インストールでは、値をバックアップできる場合に、InventorySvc、lfsvc、DoSvc のスタートアップ設定と svchost のグループ化しきい値を調整します。独自のコピー機能 (SSD では複数ファイルを同時に、大きなファイルはバッファなし、進行状況はステータス行に表示) と、右クリックの **ZIP に圧縮** (全コア) / **ここに展開** (ZIP と 7z)、独自の ZIP エンジン。`.zip` はフォルダーのように開きます (閲覧、コピー、ファイルを開く)。他のプログラムからの「フォルダーで表示」ではファイルが選択されます (ダウンロード、ドキュメント、デスクトップ、ピクチャ、ミュージック、ビデオ、ピン留めしたフォルダーなど。ウィンドウが開いていなくても動作)。マウスの戻る/進むボタンが使えます。デスクトップを右クリックするとアイコンを隠せます。topbar が必要です |
| **wiztree** | ディスク使用量マップ (スタートの「WinRust Disk」) | ファイルとショートカット以外は何も変更しません |
| **photoview** | 高速なフォト ビューアー | 「プログラムから開く」に追加します (既定にはなりません) |
| **rust-settings** | Rust 製の設定: ディスプレイ (解像度、リフレッシュ レート)、サウンド (音量)、電源プランとドライブの空き容量、アプリごとの音量とデバイスの選択、夜間モード、ドラッグによるディスプレイの配置、ネットワーク アダプター、すべてのアダプターでの Wi-Fi (パスワードまたは 802.1X)、VPN とプロキシ、Bluetooth、アプリ、Windows Update、ディスク クリーンアップ、テーマ、バージョン情報 | ファイルとショートカット以外は何も変更しません。Win+I とバーのメニューは Windows の設定の代わりにこのウィンドウを開きます (ごく一部のあまり使われないページのみ、引き続きシステムの設定を開きます) |
| **debloat** | オフにするもの: テレメトリ、診断、Copilot、Recall、スタートの広告、バックグラウンドの Edge | サービスとレジストリ ポリシー。元の値は保存され、アンインストール時に復元されます。**コマンド ラインのみ:** `install debloat --yes` |
| **purge** | Tiny11 のように、プリインストールの不要なアプリを削除します: Clipchamp、ニュース、天気、Xbox オーバーレイ、Teams、Cortana、ウィジェット、Skype など、およびテレメトリ タスク | **元に戻せません。** アプリはすべてのユーザーから、およびイメージから削除されます。Store、設定、スタート、ランタイムは残ります。まず `purge.exe` を実行してください。一覧を表示するだけです。**コマンド ラインのみ:** `install purge --yes` (OneDrive と Edge: `purge.exe --apply --onedrive --edge`) |
| chrome-rs | ブラウザー | まだインストールできません |

すべての変更は元に戻せます。アンインストールすると、以前の値が戻ります。

## スタイル

バーの左端の歯車で**バーの設定**が開きます。**テーマ**ページで選んだスタイルは、バー、ファイル マネージャー (rust-explorer)、検索ウィンドウ (Alt+Space) にすぐ反映されます。

| スタイル | 外観 |
|---|---|
| **ノーマル** | Windows 11 の青、バーは下部 |
| **ターミナル** | 黒地に緑、Consolas、角は四角 |
| **フローティング ドック** | 中央の丸いバー。最大化したウィンドウは画面全体を使い、ドックはその上から退避して、下端に触れると戻ります |
| **タイリング** | 上部の細いバー、琥珀色のアクセント、角はノーマルと同じく丸め。「ウィンドウを並べて表示」で開いているウィンドウを並べます |
| **白い道** | 象牙色に金: バー、そのパネル、rust-settings の背後に、淡いローポリの三角形 (一部は金色の線) |
| **ルビー** | 深いガーネットに明るいルビーのアクセント: バーとそのパネルの背後に、上から下へのなめらかなグラデーションとやわらかな光沢 |
| **Windows 98** (BETA) | クラシックなグレーに濃紺のアクセント、角は直角、Tahoma。色・角・フォントのみで、立体的な枠はまだありません |
| **Windows 7** (BETA) | Aero 風のガラスのような青、白い文字 |

歯車メニューでは、バーの位置 (下、左、右: 横置きのバーはアイコンのみで、パネルはその隣に開きます) と自動的に隠す設定も変更できます。

選択内容は `%ProgramData%\WinRust\style.txt` に保存されます。

## ベンチマーク

1 台のマシン (Windows 11 IoT Enterprise 10.0.26300、RTX 4060 Laptop、NTFS) での単発の測定です。実験室の数値ではなく、桁の目安として見てください。

| 項目 | Windows | WinRust | 差 |
|---|---|---|---|
| ファイル検索 (rust-search で C: 全体 vs 1 フォルダーに対する `dir /s`) | 8,340 ms | 45 ms | **99.5%** 高速 |
| 同じく `Get-ChildItem -Recurse` との比較 | 16,200 – 28,600 ms | 45 ms | **99.7–99.8%** 高速 |
| フォルダー ウィンドウを開く (rust-explorer、5 回の中央値) | 420 ms | 60 ms | **86%** 高速 |
| シェルのメモリ (topbar + rust-explorer + rs-shell + reshell vs explorer.exe) | 366 MB | 46 MB | **87%** 削減 |
| 同じく検索インデックス (53 MB) を含む | 366 MB | 99 MB | **73%** 削減 |
| ファイル マネージャーのバイナリ サイズ (ZIP と 7z を内蔵) | 3,280 KB | 1,179 KB | **64%** 縮小 |
| タスク マネージャーのバイナリ サイズ | 5,791 KB | 954 KB | **84%** 縮小 |
| バーのアイドル時 CPU (最適化後の topbar、1 コアに対する %) | 0.00–0.10% (explorer) | 0.05–0.10% | Explorer と同等 |
| 小さなファイル 5,000 個、約 160 MB のコピー (rust-explorer: IFileOperation、Explorer のエンジン vs 独自のコピー機能) | 16.3 秒 | 2.3 秒 | **86%** 高速 (7 倍) |
| 1 GB のファイル 1 個のコピー (同上) | 0.58 秒 | 0.60 秒 | 同等 |
| 同じ 5,000 ファイルを ZIP に圧縮 (`Compress-Archive` vs rust-explorer の ZIP に圧縮) | 48.4 秒 | 0.75 秒 | **98%** 高速 (64 倍) |

要約: **サイズ/速度のテストでは 64～99% の高速化または縮小。アイドル時の CPU と大きなファイル 1 個のコピーでは同等です。** 注意点: rs は用意された MFT インデックスを検索する (そのために 53 MB のメモリを使う) のに対し、`dir` と PowerShell はディスクをゼロから走査します。テスト中も explorer.exe はウィンドウを開いたまま動作していたため、メモリの削減効果はやや過大です。Windows 検索と標準のタスク マネージャーは比較していません。コピーと ZIP の測定 (`cargo test -p rust-explorer --release bench -- --ignored`) は、書き込んだばかりのデータに対する単発の実行で、どちらもメモリ キャッシュから読み込んでいます。ZIP は各ファイルを別々のコアで圧縮するため、こちらのほうがやや大きくなりました (0.9 MB 対 0.7 MB)。

### バックグラウンド負荷

常駐するプログラムの、v0.5.7 のイベント駆動への作り直し の前後の比較です。同じマシンで、アイドル状態のデスクトップ 60 秒間の CPU 時間 (プロセスの `TotalProcessorTime`)、プライベート メモリ、開いているハンドル数を測りました。「前」は作り直しの直前にインストールされていたビルドです。

| プログラム | アイドル CPU (前) | (後) | プライベート メモリ (前) | (後) | ハンドル (前) | (後) |
|---|---|---|---|---|---|---|
| topbar | 6.3 ms/秒 (1 コアの 0.63%) | 0.5 ms/秒 (0.05%) | 9.2 MB | 7.7 MB | 459 | 426 |
| rs-launcher (Alt+Space、非表示) | 6.3 ms/秒 (0.63%) | 0 | 12.7 MB | 1.4 MB | 800 | 110 |
| rs-shell | 2.1 ms/秒 (0.21%) | 0 | 1.2 MB | 1.3 MB | 95 | 102 |
| rs (検索インデックス サービス) | 0 | 0.26 ms/秒 | 59.6 MB | 56.7 MB | 70 | 70 |

変更点: バーは 1 秒に 2 回すべてのウィンドウを列挙する代わりにウィンドウのイベントを受け取り、背景は毎フレームではなく 1 回だけ描きます。rs-launcher は 2 秒ごとのプロセス一覧の全更新をやめ、rs-shell は reg.exe の起動とプロセスのスナップショットをやめました。上の表のアイドル CPU の行は、この作業の前に別の方法で測ったものです。

## 開発者向け

### 構成
```
src/            インストーラー (plugin-launcher.exe)
  main.rs         プラグイン テーブル PLUGINS: 名前、テキスト、インストール/アンインストールの組、アイコン
  install/        各プラグインが何を変更し、どう元に戻すか (プラグインごとに 1 ファイル)
  cli.rs, ui.rs   コマンド ラインとウィンドウ。どちらも同じインストール関数を呼びます
common/         winrust-common: 言語切り替え (t!/tf!: 英語、ロシア語、日本語、ブラジル ポルトガル語、簡体字中国語)、UI スタイルとパレット、reg.exe 出力のパーサー、NTFS MFT リーダー
plugins/        各プラグインのソース (それぞれ独立したクレート)
ReShell/        reshell (デスクトップのホットキー、topbar のセーフティ ネット)。topbar に同梱
payload.txt     インストーラーに埋め込まれる exe と、ビルドがそれらを置く場所
payload/        ビルド済みのそれらの exe (git には含まれません)
scripts/        ビルド、更新、リリース
```
すべて 1 つの cargo ワークスペースです (`Cargo.lock` は 1 つ、すべての exe は `target\release`)。`plugins/rust-search` と `plugins/chrome-rs` は `panic = "unwind"` が必要なため別々にビルドします (`Cargo.toml` を参照)。

### 言語の追加
`t!("русский", "english", ja: "日本語", pt: "português", zh: "中文")` と `tf!(…)` が各テキストを現在の言語で返します (`ja:`/`pt:`/`zh:` を省略するとそれらの言語では英語が表示されます)。言語は `common/src/lib.rs` の `Lang` です。

### ビルド
Windows x64、Rust stable (1.85+) の MSVC ツールチェーンが必要です。
```powershell
powershell -ExecutionPolicy Bypass -File scripts\build-all.ps1
```
結果: `target\release\plugin-launcher.exe` (すべてのプラグイン入り)。先に実行中のインストーラーを閉じてください。テスト: `cargo test --workspace` (および `plugins\rust-search` での `cargo test`)。CI は push のたびに同じことを実行します (`.github/workflows/build.yml`)。

| スクリプト | 内容 |
|---|---|
| `build-all.ps1` | すべて: プラグイン → `payload\` → インストーラー |
| `build-plugins.ps1` | プラグインのみ → `payload\` (インストーラーは再ビルドしない) |
| `update-plugin.ps1 <plugin>` | インストーラーを再ビルドせずに、インストール済みのプラグイン 1 つを再ビルドして再インストール (UAC で管理者権限を要求) |
| `user-mode.ps1`、`dev-update.ps1` | 開発者モード: topbar、rust-explorer、rs-shell、reshell を Explorer の上で `%LOCALAPPDATA%` から実行し、管理者権限なしで入れ替え |
| `bench.ps1` | 検索とタスク マネージャーのベンチマーク |
| `publish.ps1`、`release.ps1` | コミットと push。`WinRust.exe` 付きの GitHub リリース |

### コマンド ライン
**管理者権限の**ターミナルから:
```
plugin-launcher list
plugin-launcher install <plugin>... --yes (1 つ以上の名前、または既定のコンポーネントすべてを表す `all`。--yes なしでは警告を表示するだけ)
plugin-launcher update <plugin>|all        (exe の隣の payload\ から再インストール)
plugin-launcher uninstall <plugin>
plugin-launcher rollback --yes           (すべて削除)
plugin-launcher autoupdate               (今すぐ 1 回の更新確認: WinRust-update タスクが実行するもの)
```

新規の一括インストールに `rust-explorer` を含めるには、`plugin-launcher install all rust-explorer --yes` を実行します。`topbar` がすでにインストールされている場合は、`rust-explorer` だけをインストールできます。
1 回のコマンドで複数のプラグインを指定した場合は、テーブルの順序 (rust-explorer より前に topbar) でインストールされ、失敗したものがあっても残りは止まりません。終了コード: 0 は成功、1 はエラー (少なくとも 1 つのプラグインが失敗)、2 は不正な引数または `--yes` なし。引数なしではウィンドウが開きます。インストール ログ: `%ProgramData%\plugin-launcher\install.log`。

### プラグインの追加
1. `plugins/<name>` にクレートを作り、ルートの `Cargo.toml` の `members` に追加します。
2. `payload.txt` に 1 行追加します。
3. インストール/アンインストールの組を持つ `src/install/<name>.rs` (と `src/install/mod.rs` の `mod` 行)。何かを変更する前に元の値を保存し、アンインストールで戻せるようにします。
4. `PLUGINS` (`src/main.rs`) にエントリを追加します。ウィンドウ、その高さ、コマンド ラインは自動的に反映します。
